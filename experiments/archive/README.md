# Archive: the original paper's experiments

These are the experiments of the forked paper, *Biases in the Blind Spot* (arXiv 2602.10117): loan approval, university admission and hiring (`llm_bias`, résumé screening). They are not part of the financial harness, which never reads them, and they should not be rerun as part of this project. They are kept so that the paper's results stay reproducible; `tests/legacy/` still loads their stage-0 results.

The datasets, generators and hiring prompts they use are in `biases_in_the_blind_spot/archive/`.
